# Nosrati-# 🇮🇷 Nosrati ++
### زبان برنامه‌نویسی فارسی با کامپایلر و محیط توسعه اختصاصی

**Nosrati ++** یک زبان برنامه‌نویسی با کلمات کلیدی و ساختار دستورات فارسی است. هدف این پروژه فراهم‌کردن امکان برنامه‌نویسی با زبان فارسی و ایجاد تجربه‌ای ساده و قابل فهم برای برنامه‌نویسان فارسی‌زبان است.

این زبان با استفاده از کامپایلر اختصاصی، دستورات فارسی را به کد C++ تبدیل می‌کند و سپس با استفاده از G++ امکان تولید و اجرای برنامه را فراهم می‌سازد.

---

## ✨ ویژگی‌ها

- 🇮🇷 کلمات کلیدی و شناسه‌های فارسی
- ➕ عملگرهای ریاضی
- ✖️ عملگر ضرب: `×`
- ➗ عملگر تقسیم: `÷`
- 🖥️ محیط توسعه گرافیکی اختصاصی (IDE)
- ⚙️ کامپایل کدهای فارسی به C++
- ▶️ کامپایل و اجرای برنامه
- 🎨 رنگ‌بندی دستورات در ویرایشگر
- 📂 ایجاد، بازکردن و ذخیره فایل‌ها
- 📝 نمایش خروجی و پیام‌های کامپایل
- 🔢 پشتیبانی از اعداد فارسی
- 🔄 دستورات شرطی و حلقه‌ها
- 🧩 توابع و آرایه‌ها

## 🛠️ تکنولوژی‌های استفاده‌شده

| فناوری | کاربرد |
|---|---|

## 📚 فهرست لغات کلیدی (Keywords)

یکی از ویژگی‌های اصلی Nosrati ++ استفاده از لغات کلیدی فارسی به جای کلمات انگلیسی در ساختار زبان است.

### ۱. انواع داده‌ها

| لغت کلیدی | معادل | کاربرد |
|---|---|---|
| `عدد` | int / long long | تعریف عدد صحیح |
| `اعشاری` | double | تعریف عدد اعشاری |
| `رشته` | string | تعریف متن |
| `درست‌نما` | bool | تعریف مقدار منطقی |
| `منطقی` | bool | تعریف مقدار منطقی |

### ۲. دستورات ورودی و خروجی

| لغت کلیدی | کاربرد |
|---|---|
| `چاپ` | نمایش اطلاعات در خروجی |
| `ورودی` | دریافت اطلاعات از کاربر |

### ۳. دستورات شرطی

| لغت کلیدی | کاربرد |
|---|---|
| `اگر` | بررسی شرط |
| `وگرنه` | اجرای بخش جایگزین شرط |
| `آنگاه` | شروع بدنه شرط یا حلقه |
| `پایان` | پایان بلوک دستورات |

### ۴. دستورات حلقه

| لغت کلیدی | کاربرد |
|---|---|

| `تا` | تعیین مقدار پایان حلقه |

### ۵. توابع

| لغت کلیدی | کاربرد |
|---|---|
| `تابع` | تعریف تابع جدید |
| `بازگردان` | بازگرداندن مقدار از تابع |

### ۶. آرایه‌ها و کلاس‌ها

| لغت کلیدی | کاربرد |
|---|---|
